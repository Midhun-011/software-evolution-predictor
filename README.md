# Software Evolution Predictor

Full-stack sample application: React + Vite frontend and Node.js + Express backend that predicts software evolution health and risk.

Run instructions:

1. Backend

```bash
cd backend
npm install
npm run dev
```

2. Frontend

```bash
cd frontend
npm install
npm run dev
```

The frontend proxies API requests to the backend on `/api`.
